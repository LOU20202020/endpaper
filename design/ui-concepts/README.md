# Endpaper UI 概念稿

自用启动器的界面改造方向：把"书"做成界面本体，而不是贴一层书皮装饰。

## 选定方向：整窗摊开书 → 书脊 + 目录页 + 正文页

| 文件 | 说明 |
| --- | --- |
| `c5.html` / `c5.png` | **定稿结构**。80px 书脊放 8 个导航；左页是当前章节的"目录"（实例条目 + 点线引导 + 页码 + 运行中小绿点）；右页是选中实例的"正文"（封面、版本、内存、Java、开始游戏），右侧留页边批注。 |
| `c_openbook.html` / `c_openbook.png` | 初版：整窗一本摊开的书，左右各 50%，左页全目录、右页实例列表。 |
| `a_shelf.html` / `a_shelf.png` | 备选：一面木书架，实例是一本本立着的书，点书脊抽出来。 |
| `b_desk.html` / `b_desk.png` | 备选：俯视书桌，一本摊开的大书居中，左侧一摞实例书，右侧便签、铅笔、杯印。窗口缩放时道具易散架，暂不采用。 |

## 结构上的几条决定

- **导航不占宽**：8 个导航只值一条书脊（约 6% 宽）。宽导航只有能塞二级内容或能显示信息时才成立。
- **左页必须有活干**：只有"翻开的左右两页 + 中缝"才像书；但左页要装真实内容（实例目录），不能只放几行导航链接。
- **宽度换并排**：省下的横向空间用于"目录 + 正文"并排，选中即见详情，不必点进去再返回。
- **实例快速切换**：沿用原左栏那列实例按钮的职能，做成从书脊右缘探出的彩色书签签条。
- **开屏动画**：整窗翻书 → 就地变形为主界面的动画代码保留在 `apps/app-frontend/src/components/ui/SplashScreen.vue`，默认不挂载；`apps/app-frontend/src/App.vue` 里把 `SHOW_SPLASH` 改为 `true` 即可恢复。

HTML 概念稿是纯静态页面，1280×800，用无头浏览器截图即为上表 PNG；它们只用于确定结构，不是最终实现。
